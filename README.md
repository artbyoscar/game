# Voxel Dungeon Crawler

A roguelike voxel dungeon crawler built with Three.js and TypeScript.

## Features

- Procedurally generated dungeons
- First-person controls
- Voxel-based 3D graphics
- Physics and collision detection
- Dynamic lighting

## Getting Started

Install dependencies:
```bash
npm install
```

Run development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```

## Controls

- **WASD** - Move
- **Mouse** - Look around
- **Space** - Jump
- **Click** - Start game / Lock pointer
